Tiny Colony 🐜

A simulator and strategy game where you manage an ant colony to collect foods, grow in numbers and defend invasive threats to survive 2 rough weeks of attacks from giant insect species

This is a game I made in the jame gam game jam event of Hack Club with my best friends @philogamer and @vincent058
Features:
-Resource Management System (6 types of materials with different uses to strengthen your ant armies)
-Strategic Timing (Grow your workforce and your army to prepare for waves of threats)
-5 Different Soldier Ant Classes:
 -Black Ant (basic unit)
 -Leafcutter Ant (Tough tank units)
 -Wood Ant(Ranged Unit)
 -Fire Ant(Melee unit with burn damage that grows in number)
 -Dracula Ant (Lifesteal unit that has the ability to heal itself)
-Roguelike Card System that allows every run to be different and engaging:
-Every time you defeat a boss, you get to pick 1 out of 3 cards that give your run a permanent buff, these may contains cards that give each class of soldiers its potential unlock.
Controls:
Space to Start Game and Replay
Mouse Click for everything else in the game (click buttons, etc...)
Installation Guide:
Install game file from the game page: https://nnkd-kevin.itch.io/tinycolony1 (Exe file for Windows)

Built with:
-Python3
-Pygame
-Pyinstakker
